# Digi21.DigiNG.IO.Bin

This package contains reference assemblies for reading/creating [Digi3D.AI](https://www.digi21.net/Digi3D) binary files (*.bin).

The runtime assemblies are installed by Digi3D.AI. The Digi21.DigiNG package, which this package depends on, adds a source file to your C# project that locates them in the Digi3D.AI installation folder, so your console application or extension can be installed in any folder. You do not have to add any other package or write any code.

A Digi3D.AI license is required to run applications that use the assemblies published by this package. [Rent](https://www.digi21.net/Tienda/Alquiler) or [buy](https://www.digi21.net/Tienda/Compra) a license.
